## 1. 我学到的 5 件事

### 1.1 "5 库 mapping 强制 5 条" = 伪门禁

之前我把"5 条跨学科证据"当 Solidify 守门的一部分 = **没意识到这是修辞层面的装门面**。

工程权衡的真正决定因素：
- 性能 / 可维护性 / 故障恢复 / 并发模型
- **不是**生物学 / 心理学类比

承认：每个工程决策都能强行凑 5 条类比（信噪比被人为压低）。

### 1.2 门禁 vs 启发式 混淆

| 类型 | 例子 | 我之前 |
|------|------|--------|
| **门禁**（必须）| Solidify 人工审批（Arrow 不可能性） | ✅ 真门禁 |
| **启发式**（可选）| 5 库 mapping | ❌ 错当门禁 |

**修正**：5 库 mapping 只在 2 类场景强制（不可逆架构决策 + 自动化 vs 人工审批），其余 = 可选启发式。

### 1.3 数据可信度 = 缺失

之前报告"157/157 verified"、"47% UNIQUE 下降 11391→5959" 没说来源。

读者没法区分：
- 真生产数据？
- 还是本地 mock_peer.py 回放？

**修正**：CHANGELOG 每条数字加 `[SIMULATED: 本地]` / `[LIVE: 生产]` 标注 + README 加 CI badge（任何访问者可验证）+ examples/ 段（本地真能跑）。

### 1.4 过度设计（README 太复杂）

之前我加了 4 个 badge + SemVer/迭代轮次区分 + 资产分类 + 8 段脚注。

胡老师说：**"收窄范围，先把阶段1+2做扎实"** = 单条提示比复杂文档更值。

### 1.5 威胁模型 = 该早写

**A2A HMAC → ed25519 + 自我进化网络污染风险** = 这两件事我早该在 v1.0 写文档。

"自我进化" = 持续从历史生成新内容。一旦污染：
- 第 1 代：1 个恶意 Gene
- 第 4 代：1000 个（**全网失控**）

### 1.6 AI_AUTHORSHIP 故事价值

之前我以为"Agent 主导开发"是**隐性事实**，没当卖点。

胡老师说：**"用 Agent 自我进化的方式来构建 Agent 自我进化的基础设施本身就是个好故事"**。
